# Online Examination System

## 📌 Project Overview

The **Online Examination System** is a Java-based GUI application designed to conduct online examinations in a simple and user-friendly way. It allows users to answer multiple-choice questions, navigate through the examination, and view their result after submitting the test.

The project demonstrates the use of **Java, Object-Oriented Programming, GUI development, event handling, and basic application logic**.

## 🎯 Objectives

* To provide a simple platform for conducting online examinations.
* To display multiple-choice questions through a graphical interface.
* To allow users to select and submit answers.
* To calculate the score automatically.
* To display the final result after examination completion.

## ▶️ How to Run

1. Clone or download the repository.
2. Open the project in **VS Code / IntelliJ IDEA / Eclipse**.
3. Make sure **Java JDK** is installed.
4. Compile the Java source files.
5. Run the main Java class.
6. The Online Examination System GUI will open.

## 💡 Working

The application displays examination questions with multiple options. The user selects the appropriate answer and proceeds through the examination. Once all questions are completed, the system evaluates the selected answers, calculates the total score, and displays the final result.
