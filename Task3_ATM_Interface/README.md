# ATM Interface – Java

## Project Description

A console-based ATM Interface developed using Java and Object-Oriented Programming concepts. The system allows users to securely log in and perform common banking transactions such as withdrawal, deposit, transfer, and transaction history management.

## Features

- User account creation with User ID and 4-digit PIN
- Secure login with a maximum of 3 attempts
- Multiple account support
- Cash withdrawal with balance validation
- Cash deposit
- Money transfer between accounts
- Insufficient Funds validation
- Transaction history using ArrayList
- Separate transaction history for each account
- Automatic Account ID generation

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Java Date & Time API
- Console Application

## OOP Concepts Used

- Encapsulation
- Classes and Objects
- Abstraction
- Method-based modular design
